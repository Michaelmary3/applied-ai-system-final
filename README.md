# 🐶 BugHound & Music Recommender Applied AI System

BugHound is a small, agent-style debugging and recommendation intelligence tool. It analyzes data inputs, proposes logical decisions, and runs basic reliability checks before deciding whether outputs are safe and accurate to apply automatically.

---

## What BugHound Does

Given a short Python snippet or music preference input, BugHound:

1. **Analyzes** the input for potential issues  
   - Uses heuristics in offline mode  
   - Uses Gemini when API access is enabled  
   * **Answer / System Reality:** The system validates structural keys (e.g., `genre`, `mood`, `energy`) and flags any missing or out-of-bounds parameters before executing core logic.

2. **Proposes a fix or recommendation**  
   - Either heuristic-based or LLM-generated  
   - Attempts minimal, behavior-preserving changes  
   * **Answer / System Reality:** It calculates explicit match scores across genre (+2.0), mood (+1.0), and numerical energy proximity, sorting candidates from highest relevance score to lowest.

3. **Assesses risk**  
   - Scores the fix or output  
   - Flags high-risk changes  
   - Decides whether the output should be auto-applied or reviewed by a human  
   * **Answer / System Reality:** Incorporates fail-fast guardrails that halt execution and log errors whenever required input schema keys are missing or malformed.

4. **Shows its work**  
   - Displays detected issues  
   - Shows a diff or breakdown between raw and processed data  
   - Logs each agent step
   * **Answer / System Reality:** Outputs human-readable reason traces alongside numeric scores (e.g., `Genre match (+2.0), Energy proximity (+0.95)`) so users understand the exact reasoning behind every prediction.

## Original Base Project & Applied Extension

* **Original Base Project:** Music Recommender Simulation (Module 3)
* **Summary of Goals & Capabilities:** The original prototype was a simple script that read song data from a CSV file and applied rigid equality checks to generate basic recommendations.
* **Applied AI System Upgrade:** Extended into an end-to-end Applied AI System featuring agentic preference validation, weighted heuristic scoring, input guardrails, and an automated reliability test harness (`src/evaluator.py`).

## System Architecture

The architecture relies on a four-stage pipeline: Preference Parsing & Input Guardrails → Scoring & Ranking Engine → Explanation & Reason Generator → Reliability Test Harness.

The system architecture diagram is saved as a Mermaid source file at [`diagrams/architecture.mmd`](diagrams/architecture.mmd).

```mermaid
graph TD
    User[User Input / Preference Prompt] --> Parser[Preference Parser / Agent]
    Parser --> Engine[Scoring & Ranking Engine]
    Catalog[(Song Catalog / CSV Data)] --> Engine
    Engine --> Generator[AI Explanation & Reason Generator]
    Generator --> Output[Ranked Recommendations Output]
    Engine --> Evaluator[Reliability Test Harness]
    Evaluator --> Guardrails{Guardrails & Metrics}
    Guardrails -->|Pass| Terminal[Terminal Output Log]
    Guardrails -->|Fail| Logging[Error Log / Fallback]
